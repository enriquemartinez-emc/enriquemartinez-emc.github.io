# Enrique Martinez Portfolio

An animated software portfolio built with Next.js, TypeScript, Tailwind CSS, GSAP, and Lenis.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```

The site is statically exported and deployed through GitHub Pages by `.github/workflows/deploy-nextjs.yml`.

## Scene assets

The desktop WebGL scene uses the animated `Xbot.glb` example asset served by the three.js project as a temporary explorer stand-in. Verify the asset's terms or replace it with a production-licensed astronaut GLB before publishing a final portfolio release. The scene code and renderer are original project code.
