# Enrique Martinez Portfolio

A personal website for Enrique Martinez, a professional software engineer. It presents full-stack experience, technical skills, and contact paths through a scroll-driven spaceflight scene built with Next.js, TypeScript, Three.js, GSAP, and Lenis.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```

The site is statically exported and deployed through GitHub Pages by `.github/workflows/deploy-nextjs.yml`.

## Scene assets

The desktop WebGL scene has no third-party runtime assets. Its environment, explorer geometry, materials, lighting, and effects are original project code bundled with the site.
